# FastBite - Modern Food Delivery App

A fully functional food ordering application built with React and Redux Toolkit, rebranded with a modern vibrant theme.

### Key Features:
---
- **Dynamic Search & Filtering:** Find your favorite foods quickly with real-time search.
- **Wishlist / Favorites:** Save your preferred items for later with a dedicated wishlist view.
- **Add to Cart:** Seamless shopping experience with Redux state management.
- **Interactive Shopping Cart:** View, add, and remove items with real-time price updates.
- **Checkout Flow:** Complete order flow including a detailed checkout page.
- **Modern Minimalist UI:** Rebranded with a fresh orange-themed aesthetic.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.

### Technologies Used:
---
1. **React.js** - Frontend framework.
2. **Redux Toolkit** - Global state management for cart, wishlist, and auth.
3. **ReactStrap** - Bootstrap-based components for layout.
4. **Remix Icons** - Modern icon pack.
5. **CSS Variables** - Easy-to-manage theme colors.

### How to Start?
---
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
